# Glossary

* Baseline: the first before photo for a place
* C2PA: a seal inside the file that says which camera made it and if it changed
* EXIF: camera data like time, lens, GPS
* Homography: math that warps one photo to match the view of another
* IQA: score for how clear the photo is
* MRV: check and report steps used by funders
* NDVI delta: change in plant cover between two shots
* Proof pack: zip with images, hashes, seals, AI logs, and video links
